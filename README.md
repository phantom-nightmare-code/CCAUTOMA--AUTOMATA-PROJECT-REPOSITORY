1. Prerequisite: Python 3.6 or Higher
You must have Python installed. If you don't, download it from python.org.

CRITICAL: During the installation, check the box that says "Add Python to PATH" at the very bottom of the installer window. This is the most important step.

2. Command Prompt "Credentials" (PATH Configuration)
The Command Prompt doesn't need a username/password. It needs to know the file path to the Python executable.

Here is how to check if your Command Prompt has the right "credentials" (PATH setup):

Open Command Prompt (type cmd in the Windows search bar and press Enter).

Type the following and press Enter:
python --version

If it shows Python 3.10.x (or similar): You are good to go! No further setup is needed.

If it shows 'python' is not recognized as an internal or external command: That means Python is installed, but the Command Prompt doesn't know where to find it.
